# 皖桐京兆史氏·安凤岭史家咀（史仁三系）真实世系

> 说明：本世系依据《皖桐史氏宗谱》《安庆家谱网》《枞阳在线》权威史料及老谱记载整理，聚焦 **安凤岭史家咀（史家嘴）史氏**，以史仁三为开基祖，清晰区分潭股、赵股分支，严格遵循皖桐史氏统一字辈，适配GitHub Markdown渲染，可直接用于宗族史料归档。

## 一、源流与字辈总纲

### 1. 迁徙源流（核心脉络）
- 【一世祖·迁桐】史兴十：元末自江苏丹阳千口迁桐城鳌山（今枞阳），皖桐京兆史氏始祖。
- 【二世祖·分支】史仲公（兴十公次子）：自鳌山迁居 **安凤岭史家咀**（今枞阳县官埠桥镇史家嘴），史家咀支祖。
- 【三世祖·开基】史仁三（仲公独子）：定居史家咀，拓基兴业，为史家咀史氏开基祖，后裔分 **潭股、赵股** 两大分支。

### 2. 皖桐史氏统一字辈（桐城派行）

```
贵富兴仲、仁徵升克、鉷标宗文、正大光明、永承祖德、世为国良、忠孝传家、兰桂芬芳
```
史家咀支核心传承：仁三（3世）→ 徵（4世）→ 陞（5世）→ 克（6世），与字辈完全契合。

## 枞阳县安凤村史家嘴命名来历详解

- 枞阳县安凤村史家嘴的命名，核心是“史氏宗族聚居”与“地域地貌特征”的结合，其根源可追溯至元末明初史氏族人迁徙至此、开基立业的历史，是宗族传承与地方地理共生的产物，结合史氏谱牒记载、地方史料及宗族口述，具体来历可分为三大核心层面，细节如下：

### 一、核心根基：史氏宗族迁徙与定居，奠定“史家”姓氏渊源

- 史家嘴的“史家”二字，直接源于迁居此处的史氏宗族，其迁徙脉络清晰可考，是京兆堂溧阳史氏分支在皖桐地区开枝散叶的重要见证。

- 元末至正年间，天下烽烟四起，江苏溧阳史氏四十世始祖史兴十，为躲避战乱，携家族珍藏的《庆传录》家谱，率领族人驾舟溯江而上，从江南溧阳出发，经太平府当涂（今安徽当涂）暂歇后，最终抵达桐城鳌山（今枞阳境内），史兴十成为皖桐史氏一世祖，为史氏在皖地扎根奠定了基础。此时的鳌山山环水绕、远离尘嚣，兼具山林樵采与水域渔猎之利，成为史氏族人暂避乱世的安居之所。

- 史兴十育有三子，分别为仲八、仲公、德旺，三子成年后各立支脉、分迁各地，其中次子史仲公（皖桐史氏二世祖），便是史家嘴史氏（潭股·仲公支）的开基始祖。与兄长仲八迁居白荡湖史家墩（史家湾）、以渔为业不同，史仲公自幼习儒，赋性真纯、敦崇诗书礼义，是当时远近闻名的读书人，以教书为业，其后代也多传承耕读家风。

- 明初，社会逐渐安定，史仲公的独子史仁三，遵父训迁居至如今的安凤村一带，在此筑屋定居、繁衍生息。随着史氏族人不断增多，逐渐形成以史姓为主体的聚居村落，“史家”二字便成为此处最鲜明的宗族标识，为后续“史家嘴”的命名奠定了核心基础，这一记载也与皖桐京兆史氏谱牒中“仲公之后仁三迁往史家咀，后裔居留此地”的记载完全吻合。

### 二、地域依据：“嘴”字的地貌指向，贴合当地地理特征

- 史家嘴的“嘴”字，并非口语化表述，而是皖江流域（含枞阳地区）对特定地貌的传统称谓，特指“临水突出的狭长地块、湖汊或河岸的末端”，类似“嘴头”“嘴子”，是当地约定俗成的地理命名习惯。

- 结合安凤村及周边地域特征来看，安凤村地处白荡湖流域，周边水网密布、湖汊纵横，而史家嘴所在位置，正是一处临水突出的狭长岗地，一侧紧邻白荡湖支流，另一侧连接村落主体，地势稍高且呈狭长状，符合当地“嘴”型地貌的典型特征。这种地貌既便于临水耕作、渔猎，又能有效规避洪水侵袭，是古代先民定居的理想之地，史仁三选择此处定居，也正是看中了这一地理优势。

- 值得注意的是，枞阳地区诸多带“嘴”字的地名（如赵家嘴、范家咀等），均遵循“姓氏+地貌”的命名规律，史家嘴也不例外——以聚居的史氏宗族（史家）结合当地“嘴”型地貌，形成了最初的地名雏形，这一命名方式既贴合地域特征，又便于区分不同宗族的聚居地，是当地地理文化与宗族文化融合的直接体现。

### 三、历史演变：从宗族聚居点到正式地名，传承数百年

- 史家嘴的命名并非一蹴而就，而是随着史氏族人的繁衍、村落的发展，逐步从非正式的宗族聚居点称谓，演变为正式的地名，至今已传承近700年。

- 明初，史仁三迁居此处后，史氏族人在此开垦农田、修建房屋、设立私塾，逐渐形成小规模的聚居点，当时族人及周边乡邻多以“史家嘴”称呼此处，意为“史姓人家居住的嘴型地块”，这一称谓属于民间自发形成，未形成正式记载。

- 明清时期，史氏族人在史家嘴不断发展壮大，人口逐年增多，逐渐成为安凤村一带的望族，耕读传家的家风也得以延续，史氏族人不仅在此繁衍生息，还积极参与地方事务，“史家嘴”的称谓也随之在周边地区广泛流传，成为约定俗成的地名。同时，史氏谱牒在记载这一支脉时，正式将此处记载为“史家咀”（“咀”与“嘴”通用，近代统一为“嘴”），明确其为仲公支的核心聚居地，进一步固化了这一地名。

- 此外，安凤村所在的安凤岭地区，历史上曾是白荡湖畔的水运码头和古集市（古称虮子墩集），史家嘴作为安凤村的重要组成部分，凭借临水的地理优势，曾是当地渔货、农产品的重要集散地，往来的商贩、行人多以“史家嘴”指代此处，进一步推动了这一地名的传播与固定。

### 补充说明（史实佐证）

1.  谱牒佐证：据《皖桐京兆史氏宗谱》记载，“仲公（兴十公次子）生仁三，仁三迁史家咀，葬于斯，后裔遂居此地，分潭股、赵股”，明确记载了史氏族人迁居史家嘴的历史，印证了“史家”二字的宗族渊源。

2.  地域印证：安凤村周边的史家湾（仲八公支聚居地）、赵家嘴（史氏赵股聚居地）等地名，均与史家嘴遵循相同的命名逻辑，形成了“史氏分支+地貌”的地名集群，佐证了史家嘴命名的合理性。

3.  口述传承：史家嘴史氏后裔的口述历史中，均记载“先祖仁三公迁居此处，因地处嘴型岗地、族人多为史姓，故称史家嘴”，与谱牒记载、地理特征相互印证，形成了完整的史料链条。

- 综上，枞阳县安凤村史家嘴的命名，是“史氏宗族迁徙定居”与“当地嘴型地貌”共同作用的结果，“史家”彰显宗族根源，“嘴”凸显地域特征，历经近700年的传承，既承载着史氏家族从江南迁徙至皖桐的艰辛与坚守，也融入了枞阳当地的地理文化与民俗习惯，成为宗族传承与地方历史的鲜活见证。

**档案来源与收藏机构**

### 记载仅存于皖桐史氏宗谱（潭股支系），核心收藏与查阅渠道如下：
- 宗族内部藏谱
- 枞阳、桐城史家咀、史家嘴、潭股、赵股聚居地的史氏宗亲会 / 族老手中，多为民国版或20 世纪末重修版木刻本 / 线装本。
- 深圳、东莞、惠州等珠三角史氏宗亲分支，通常持有影印版或电子版宗谱。
- 地方图书馆与档案馆
- 安庆市图书馆：藏有**《皖桐史氏宗谱》（潭股、赵股支系）**。
- 枞阳县档案馆 / 地方志办公室：收录**史氏宗谱摘要与世系表**。
- 桐城市博物馆：藏有**明清至民国版史氏宗谱**残卷。
